## Finding Duplicate Lines
1. Go的else必須緊接在`}`之後, 不可以成為一行的開頭.
    ```go
    if condition {
        ...
    } else {
        ...
    }
    ```
2. function和其它package level的entities的declaration順序不影響reference.
3. map是一種reference type, 可以傳入function修改內容.
4. package `ioutil`的functions自1.16後由package `io`和`os`的functions取代.
