## Loose Ends
1. switch的default case位置可以不用放在最後
2. tagless switch
    ```go
    func Signum(x int) int {
        switch {
        case x > 0:
            return +1
        default:
            return 0
        case x < 0:
            return -1
        }
    }
    ```
3. Go的pointer不支援pointer arithmetic
4. Go的註解有二種, 單行註解`//`和多行註解`/* ... */`
