## Command-Line Arguments
1. slice s的表達式: s[m:n], 0 <= m <= n <= len(s), 其中m和n都可以省略, 省略的話m = 0, n = len(s).
2. 和C/C++不一樣, Go只有i++, i--, 沒有++i, --i.
3. Go只有一種loop construct *for*, 其語法如下, 每一部分都可以省略:
    ```go
    for initialization; condition; post {
        ...
    }

    // the while equivalent
    for condition {
        ...
    }
    ```
4. Go也支援range based的for loop:
    ```go
    // i is index, v is os.Args[i]
    for i, v := range os.Args[1:] {
        ...
    }
    ```
5. `_`在Go稱為blank identifier, 通常當做temp variable使用, 因為Go不允許unused variables.
