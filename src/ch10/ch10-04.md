## Import Declarations
1. multiple imports通常都以下面方式呈現:
    ```go
    import (
        "fmt"
        "os"
    )
    //
    // which is equivalent to:
    // import "fmt"
    // import "os"
    //
    ```
2. gofmt和goimports會對import packages依不同domain做grouping(group間會插入空白行)
3. renaming import可以避免不同import path但是同package name造成的conflicts
    ```go
    import (
        "crypto/rand"
        mrand "math/rand"
    )
    ```
