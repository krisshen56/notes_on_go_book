## The Package Declarations
1. 每個Go程式碼檔案都是由package宣告開始, 也是被其它package import時的package name
2. package name通常都是import path的最後一段字串, 但有例外:
   - Go執行檔程式的package name都是main
   - package目錄下的external test package(由*_test.go檔案組成), 其package name另有_test的後綴
   - 有版本號後綴的import path, ex: `import "gopkg.in/yaml.v3"`, package name仍然是yaml
